# PLAN.md — AERO-04: Flight Dynamics From Scratch

## Overview
A from-scratch implementation of aircraft flight mechanics and dynamics — 6-degree-of-freedom equations of motion, static and dynamic stability analysis, and simulation of classical flight modes. Fourth of five projects covering the classical pillars of aerospace engineering.

## Objective
Build a flight dynamics simulation toolkit that derives an aircraft's equations of motion from aerodynamic/mass/inertia properties, linearizes them about trim conditions, and reproduces the classical longitudinal and lateral-directional modes (phugoid, short period, dutch roll, spiral, roll).

## Why This Project
Flight dynamics is where aerodynamics, propulsion, and structures come together as a *system* — it's the natural bridge toward the Aircraft Conceptual Design capstone project, and it's the pillar most directly tied to flight test data and operational aircraft behavior, which connects naturally to your reliability/data engineering background (flight data analysis, FDR/QAR-style time series).

## Knowledge Covered
1. **6-DOF Equations of Motion**: derive and implement the full nonlinear rigid-body equations of motion (forces, moments, Euler angles or quaternions for attitude), using aerodynamic force/moment coefficients as inputs.
2. **Aerodynamic Derivatives**: implement the standard stability derivative model (Cl_alpha, Cm_alpha, Cn_beta, etc.) — reuse the aerodynamic modeling approach from the Aerodynamics From Scratch project where applicable.
3. **Trim Analysis**: solve for trim conditions (steady, level flight) given aircraft configuration and CG location.
4. **Linearization and Modal Analysis**: linearize the 6-DOF equations about a trim point, extract the state-space (A, B) matrices, compute eigenvalues to identify classical modes:
   - Longitudinal: phugoid, short period
   - Lateral-directional: dutch roll, spiral, roll subsidence
5. **Nonlinear Simulation**: simulate full nonlinear response to control inputs (elevator, aileron, rudder doublets) and compare against the linearized mode predictions.
6. **Stability and Control Trade Studies**: explore how CG location, tail size, and control surface effectiveness affect static margin and dynamic mode characteristics.

## Prerequisites / Background
- Newtonian mechanics (rigid body dynamics, moments of inertia)
- Linear systems / state-space representation
- Basic control theory (eigenvalues, stability)

## Data / Dataset
- **Reference aircraft**: published geometry, mass properties, and stability derivatives for textbook reference aircraft (e.g., the Navion and a generic jet transport, as tabulated in standard flight dynamics textbooks).
- **Atmosphere model**: International Standard Atmosphere.
- **Aerodynamic inputs**: optionally generated by the AERO-01 vortex lattice solver.
- No flight-test or proprietary data required.

## Tech Stack
- Python, NumPy, SciPy (eigenvalue analysis, ODE integration)
- Matplotlib/Plotly for time-domain response plots, root locus, mode shape animations
- Pytest for validation against known aircraft stability derivative datasets (e.g., published data for a reference aircraft like the Navion or a generic transport)

## Execution Plan
- [ ] **Phase 1 — Equations of motion**: implement the nonlinear 6-DOF rigid-body equations, validate against simplified textbook motion cases (e.g., pure pitching motion with no aerodynamics).
- [ ] **Phase 2 — Aerodynamic derivative model**: implement the standard linear stability derivative representation of aerodynamic forces/moments.
- [ ] **Phase 3 — Trim solver**: implement a numerical solver for trim angle of attack/elevator deflection given aircraft configuration.
- [ ] **Phase 4 — Linearization and modal analysis**: linearize about trim, extract state-space matrices, compute and classify eigenvalues into the classical flight modes.
- [ ] **Phase 5 — Nonlinear simulation**: simulate full nonlinear response to control doublets, compare time constants/frequencies against the linear mode predictions from Phase 4.
- [ ] **Phase 6 — Stability trade studies**: sweep CG location and tail volume coefficient, show their effect on static margin and dynamic mode damping/frequency.
- [ ] **Phase 7 — Documentation and publishing**: written explanation of each mode's physical meaning, animated visualizations of aircraft response.

## Validation Strategy
- Linearized mode frequencies/damping ratios compared against published values for a reference aircraft with known stability derivatives.
- Nonlinear simulation response checked for consistency with linear predictions in the small-perturbation regime.
- Trim solver validated against hand-calculated trim conditions for simple configurations.

## Deliverables
- Public repository with a documented 6-DOF flight dynamics simulator
- Validation report comparing modal characteristics against published reference aircraft data
- Visualizations: time-domain responses to control inputs, root locus plots, animated mode shapes

## Portfolio Differentiators
- Flight dynamics simulation from first principles (not just using a black-box tool like JSBSim) is a rare, high-signal project even among aerospace engineering graduates.
- Sets up the vehicle-level model needed for the Aircraft Conceptual Design capstone, and is a natural base for a future flight-test data analysis extension.
